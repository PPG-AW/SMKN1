D. Pemahaman Bermakna

  • Kuartil membagi data menjadi empat bagian sama banyak.
  • Q2 sama dengan median, sedangkan Q1 dan Q3 menunjukkan batas bawah dan batas atas bagian tengah data.
  • Range menunjukkan selisih nilai terbesar dan terkecil.
  • IQR menunjukkan lebar 50 persen data tengah sehingga lebih stabil terhadap nilai ekstrem.
  • Pada data kelompok, kuartil dihitung dengan rumus karena nilai data tidak tampil satu per satu.

5. Materi Ajar

A. Apersepsi Kontekstual

Dalam kehidupan sehari hari, kita tidak hanya perlu mengetahui nilai tengah suatu data, tetapi juga seberapa tersebar data tersebut. Misalnya, dua toko bisa memiliki rata rata penjualan yang sama, tetapi salah satu toko penjualannya sangat fluktuatif sedangkan yang lain stabil. Untuk mengukur penyebaran data, kita menggunakan kuartil dan jangkauan.

B. Pengertian dan Istilah Penting

IstilahPengertian
KuartilNilai yang membagi data yang telah diurutkan menjadi empat bagian sama banyak. Terdapat tiga kuartil yaitu Q1, Q2, dan Q3.

Q2 (Kuartil Tengah)Sama dengan median, membatasi 50 persen data.
Q3 (Kuartil Atas)Membatasi 75 persen data terbawah.
Range (Jangkauan)Selisih antara data terbesar dan data terkecil.
IQR (Jangkauan Interkuartil)Selisih antara Q3 dan Q1. Mengukur sebaran 50 persen data di tengah.
Metode Membagi DataMenentukan kuartil data tunggal dengan cara membagi data menjadi dua bagian lalu mencari median masing masing bagian.
Metode Rumus LetakMenentukan kuartil data tunggal menggunakan rumus letak. Jika posisi bukan bilangan bulat, dilakukan interpolasi.

D. Scaffolding Materi: Data Tunggal

D.1. Mengurutkan Data

Sebelum menentukan kuartil, data harus diurutkan dari terkecil ke terbesar.

Contoh: Data penjualan harian toko (ribu rupiah):

Data belum terurut: 85, 42, 67, 55, 73, 91, 48, 63, 78, 50, 88

Data sudah terurut: 42, 48, 50, 55, 63, 67, 73, 78, 85, 88, 91

Jumlah data: \(n = 11\)

D.2. Menentukan Q2 (Median)

KondisiCara Menentukan Q2
\(n\) ganjilQ2 adalah data yang tepat di tengah. Posisi Q2 = data ke-\(\frac{n+1}{2}\).
\(n\) genapQ2 adalah rata rata dua data di tengah. Posisi Q2 = rata rata data ke-\(\frac{n}{2}\) dan data ke-\(\frac{n}{2}+1\).

Contoh (n = 11, ganjil):

Data: 42, 48, 50, 55, 63, 67, 73, 78, 85, 88, 91

Posisi Q2 = data ke-\(\frac{11+1}{2}\) = data ke-6 = 67

D.3. Menentukan Q1 dan Q3 dengan Metode Membagi Data

Setelah Q2 ditemukan, data dibagi menjadi dua bagian:

  • Data bagian bawah: semua data di bawah Q2 (tidak termasuk Q2 jika n ganjil).
  • Data bagian atas: semua data di atas Q2 (tidak termasuk Q2 jika n ganjil).
  • Q1 adalah median dari data bagian bawah.
  • Q3 adalah median dari data bagian atas.

Contoh (n = 11):

Data bagian bawah: 42, 48, 50, 55, 63 (5 data). Q1 = data ke-3 = 50

Data bagian atas: 73, 78, 85, 88, 91 (5 data). Q3 = data ke-3 = 85

D.4. Menentukan Q1 dan Q3 dengan Metode Rumus Letak

\[ \text{Letak } Q_1 = \text{data ke-}\frac{n+1}{4} \qquad \text{Letak } Q_2 = \text{data ke-}\frac{2(n+1)}{4} \qquad \text{Letak } Q_3 = \text{data ke-}\frac{3(n+1)}{4} \]

Jika posisi letak bukan bilangan bulat, lakukan interpolasi antara dua data terdekat.

Contoh (n = 11):

  • Letak Q1 = data ke-\(\frac{12}{4}\) = data ke-3 = 50
  • Letak Q2 = data ke-\(\frac{24}{4}\) = data ke-6 = 67
  • Letak Q3 = data ke-\(\frac{36}{4}\) = data ke-9 = 85

D.5. Contoh dengan n Genap

Data pengunjung toko per hari (orang): 12, 15, 18, 22, 25, 28, 31, 35

\(n = 8\) (genap)

Metode Membagi Data:

  • Q2 = rata rata data ke-4 dan ke-5 = \(\frac{22+25}{2} = 23{,}5\)
  • Data bagian bawah: 12, 15, 18, 22. Q1 = rata rata data ke-2 dan ke-3 = \(\frac{15+18}{2} = 16{,}5\)
  • Data bagian atas: 25, 28, 31, 35. Q3 = rata rata data ke-2 dan ke-3 = \(\frac{28+31}{2} = 29{,}5\)

Metode Rumus Letak:

  • Letak Q1 = data ke-\(\frac{9}{4}\) = data ke-2,25 = 15 + 0,25 x (18 dikurangi 15) = 15 + 0,75 = 15,75
  • Letak Q2 = data ke-\(\frac{18}{4}\) = data ke-4,5 = 22 + 0,5 x (25 dikurangi 22) = 22 + 1,5 = 23,5
  • Letak Q3 = data ke-\(\frac{27}{4}\) = data ke-6,75 = 28 + 0,75 x (31 dikurangi 28) = 28 + 2,25 = 30,25
Catatan: Metode Membagi Data dan Metode Rumus Letak bisa menghasilkan nilai Q1 dan Q3 yang berbeda pada data genap.

D.6. Range Data Tunggal

\[ \text{Range} = x_{maks} - x_{min} \]

Contoh (data toko, n = 11):

Range = 91 dikurangi 42 = 49 ribu rupiah.

D.7. IQR Data Tunggal

\[ \text{IQR} = Q_3 - Q_1 \]

Contoh:

IQR = 85 dikurangi 50 = 35 ribu rupiah.

Perbedaan Range dan IQR:
  • Range mengukur selisih data terbesar dan terkecil, sehingga mudah terpengaruh oleh nilai ekstrem.
  • IQR mengukur sebaran 50 persen data di tengah (antara Q1 dan Q3), sehingga lebih stabil terhadap nilai ekstrem.
