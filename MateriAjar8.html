Apa itu Kuartil?

Bayangkan kamu memiliki data penjualan harian sebuah toko selama satu bulan. Kamu sudah tahu cara mencari median yang membagi data menjadi dua bagian sama banyak. Tapi bagaimana kalau kamu ingin membagi data menjadi empat bagian sama banyak?

Di sinilah kuartil berperan. Kuartil adalah nilai yang membagi data yang sudah diurutkan menjadi empat bagian sama banyak, masing-masing sebesar 25 persen.

Tiga kuartil:
  • Q1 (Kuartil Bawah) membatasi 25 persen data terbawah
  • Q2 (Kuartil Tengah) sama dengan median, membatasi 50 persen data
  • Q3 (Kuartil Atas) membatasi 75 persen data terbawah

Mengurutkan Data

Sebelum menentukan kuartil, data harus diurutkan dari nilai terkecil ke nilai terbesar. Tanpa mengurutkan, posisi Q1, Q2, dan Q3 tidak bisa ditentukan dengan benar.

Contoh

Data penjualan harian toko (ribu rupiah):

Data belum terurut: 85, 42, 67, 55, 73, 91, 48, 63, 78, 50, 88

Data sudah terurut: 42, 48, 50, 55, 63, 67, 73, 78, 85, 88, 91

Selalu urutkan data terlebih dahulu sebelum menentukan kuartil. Ini langkah paling mendasar yang sering terlewatkan.

Cek Pemahaman Bagian 2

Urutkan data berikut dari terkecil ke terbesar: 25, 10, 18, 35, 22, 15, 30

Ketik angka dipisahkan koma, contoh: 1, 2, 3

Cari angka yang paling kecil dulu, lalu yang paling kecil berikutnya, dan seterusnya sampai semua data tertulis.
3
Menentukan Q2 (Median) Data Tunggal

Q2 sama dengan median. Cara mencarinya bergantung pada jumlah data ganjil atau genap.

KondisiCara Menentukan Q2
\(n\) ganjilQ2 = data yang tepat di tengah. Posisi = data ke-\(\frac{n+1}{2}\)
\(n\) genapQ2 = rata-rata dua data di tengah. Posisi = rata-rata data ke-\(\frac{n}{2}\) dan ke-\(\frac{n}{2}+1\)

Contoh 1: n ganjil

Data (n = 7): 5, 8, 12, 15, 20, 25, 30

Posisi Q2 = data ke-\(\frac{7+1}{2}\) = data ke-4 = 15

Contoh 2: n genap

Data (n = 8): 12, 15, 18, 22, 25, 28, 31, 35

Q2 = rata rata data ke-4 dan ke-5 = \(\frac{22+25}{2} = 23{,}5\)

Cek Pemahaman Bagian 3

Soal A (n ganjil): Data sudah terurut: 4, 8, 12, 16, 20. Tentukan Q2.

Soal B (n genap): Data sudah terurut: 10, 14, 18, 22, 26, 30. Tentukan Q2.

Soal A: n = 5 (ganjil), Q2 = data ke-(5+1)/2 = data ke-3. Soal B: n = 6 (genap), Q2 = rata rata data ke-3 dan data ke-4 = (18 + 22) / 2.

Menentukan Q1 Data Tunggal

Ada dua metode untuk menentukan Q1 pada data tunggal, yaitu Metode Membagi Data dan Metode Rumus Letak.

Metode Membagi Data

Setelah Q2 ditemukan, bagi data menjadi dua bagian:

  • Data bagian bawah: semua data di bawah Q2 (tidak termasuk Q2 jika n ganjil)
  • Q1 = median dari data bagian bawah
Perhatikan: jika n ganjil, Q2 tidak boleh disertakan ke dalam data bagian bawah maupun data bagian atas. Banyak siswa yang keliru karena ikut memasukkan Q2 ke salah satu bagian.

Contoh 1: n ganjil (n = 11)

Data: 42, 48, 50, 55, 63, 67, 73, 78, 85, 88, 91

Q2 = 67 (data ke-6)

Data bagian bawah (tidak termasuk Q2): 42, 48, 50, 55, 63 (5 data)

Q1 = median dari 5 data = data ke-3 = 50

Metode Rumus Letak

\[ \text{Letak } Q_1 = \text{data ke-}\frac{n+1}{4} \]

Jika posisi letak bukan bilangan bulat, lakukan interpolasi antara dua data terdekat.

Contoh 1: n ganjil (n = 11)

Data: 42, 48, 50, 55, 63, 67, 73, 78, 85, 88, 91

Letak Q1 = data ke-\(\frac{11+1}{4}\) = data ke-\(\frac{12}{4}\) = data ke-3

Q1 = data ke-3 = 50

Contoh 2: n genap (n = 8)

Data: 12, 15, 18, 22, 25, 28, 31, 35

Letak Q1 = data ke-\(\frac{8+1}{4}\) = data ke-\(\frac{9}{4}\) = data ke-2,25

Interpolasi: data ke-2 = 15, data ke-3 = 18

Q1 = 15 + 0,25 x (18 dikurangi 15) = 15 + 0,75 = 15,75

Pada n ganjil (n = 11), kedua metode menghasilkan Q1 = 50. Pada n genap (n = 8), Metode Membagi Data menghasilkan Q1 = 16,5 sedangkan Metode Rumus Letak menghasilkan Q1 = 15,75. Keduanya benar, siswa boleh menggunakan salah satu metode.

Range (Jangkauan) Data Tunggal

Range atau jangkauan adalah selisih antara data terbesar dan data terkecil. Range menunjukkan seberapa lebar sebaran data secara keseluruhan.

\[ \text{Range} = x_{maks} - x_{min} \]

Contoh

Data penjualan harian toko (n = 11): 42, 48, 50, 55, 63, 67, 73, 78, 85, 88, 91

Range = 91 dikurangi 42 = 49 ribu rupiah

Range mudah dihitung, tetapi kelemahannya adalah mudah terpengaruh oleh nilai ekstrem. Misalnya, jika ada satu hari dengan penjualan sangat tinggi atau sangat rendah, Range akan berubah drastis.

Cek Pemahaman Bagian 6

Data harga barang (ribu rupiah): 15, 22, 28, 35, 40, 48, 55, 62, 70

Tentukan Range dari data tersebut.

Range = data terbesar dikurangi data terkecil = 70 dikurangi 15 = ?

IQR (Jangkauan Interkuartil) Data Tunggal

IQR atau Jangkauan Interkuartil adalah selisih antara Q3 dan Q1. IQR mengukur sebaran 50 persen data di tengah, yaitu data antara Q1 dan Q3.

\[ \text{IQR} = Q_3 - Q_1 \]

Contoh

Data penjualan harian toko (n = 11): 42, 48, 50, 55, 63, 67, 73, 78, 85, 88, 91

Dari perhitungan sebelumnya: Q1 = 50 dan Q3 = 85

IQR = 85 dikurangi 50 = 35 ribu rupiah

Contoh perbandingan

Data pengunjung toko 9 hari: 5, 12, 18, 25, 30, 42, 55, 68, 120

Q1 = 15, Q3 = 61,5

Range = 120 dikurangi 5 = 115

IQR = 61,5 dikurangi 15 = 46,5

Range (115) jauh lebih besar dari IQR (46,5) karena ada nilai 120 yang sangat jauh dari data lainnya. IQR lebih stabil karena tidak terpengaruh oleh nilai 120 tersebut.

Letak Kuartil Data Kelompok

Pada data kelompok, data sudah diringkas dalam tabel distribusi frekuensi sehingga nilai individual tidak terlihat. Oleh karena itu, kuartil data kelompok memerlukan rumus.

Langkah pertama adalah menentukan letak kuartil:

KuartilLetak
Q1\(\frac{n}{4}\)
Q2\(\frac{2n}{4} = \frac{n}{2}\)
Q3\(\frac{3n}{4}\)
Letak kuartil data tunggal = \(\frac{i(n+1)}{4}\), sedangkan data kelompok = \(\frac{i \cdot n}{4}\). Jangan tertukar.

Menentukan Kelas Kuartil

  1. Hitung letak kuartil
  2. Lihat kolom fk
  3. Cari fk pertama yang mencapai atau melewati letak kuartil
  4. Kelas pada baris tersebut adalah kelas kuartil

Contoh

Kelas\(f\)fk
10 sampai 1955
20 sampai 29813
30 sampai 391225
40 sampai 491035
50 sampai 59540

\(n = 40\). Letak Q1 = \(\frac{40}{4} = 10\). fk pertama yang mencapai atau melewati 10 adalah 13 pada kelas 20 sampai 29.

Cek Pemahaman Bagian 8

Gunakan tabel di atas (n = 40). Tentukan letak Q3 dan kelas Q3.

Letak Q3 = 3 x 40 / 4 = 30. Cari fk pertama yang mencapai atau melewati 30. fk = 25 belum cukup, fk = 35 sudah melewati. Kelas pada fk = 35 adalah?

Sekarang kita akan menghitung Q1 data kelompok secara lengkap.

Contoh Lengkap

Langkah 1: Hitung letak Q1

Letak Q1 = \(\frac{1 \times 40}{4} = 10\)

Langkah 2: Tentukan kelas Q1

fk pertama yang mencapai atau melewati 10 adalah 12 pada kelas 20 sampai 39

Langkah 3: Identifikasi komponen

Tb = 19,5, p = 20, F = 4, f = 8

Langkah 4: Substitusi ke rumus

Tuliskan rumus terlebih dahulu:

\[ Q_1 = Tb + p \times \frac{\frac{n}{4} - F}{f} \]

Masukkan nilai:

\[ Q_1 = 19{,}5 + 20 \times \frac{10 - 4}{8} = 19{,}5 + 20 \times \frac{6}{8} = 19{,}5 + 15 = 34{,}5 \]
Q1 = 34,5. Artinya 25 persen pengeluaran harian berada di bawah 34.500 rupiah.

Menghitung Q2 dan Q3 Data Kelompok

Cara menghitung Q2 dan Q3 sama persis dengan Q1, hanya berbeda pada letak kuartilnya.

Menghitung Q2 (Median Data Kelompok)

Menggunakan tabel pengeluaran harian (n = 40, p = 20):

Tuliskan rumus:

\[ Q_2 = Tb + p \times \frac{\frac{2n}{4} - F}{f} \]

Letak Q2 = 20. Kelas Q2 = 40 sampai 59. Tb = 39,5, F = 12, f = 12.

\[ Q_2 = 39{,}5 + 20 \times \frac{20 - 12}{12} = 39{,}5 + 13{,}33 = 52{,}83 \]
Q2 data kelompok sama dengan median data kelompok yang sudah dipelajari pada pertemuan sebelumnya.

Menghitung Q3

Tuliskan rumus:

\[ Q_3 = Tb + p \times \frac{\frac{3n}{4} - F}{f} \]

Letak Q3 = 30. Kelas Q3 = 60 sampai 79. Tb = 59,5, F = 24, f = 10.

\[ Q_3 = 59{,}5 + 20 \times \frac{30 - 24}{10} = 59{,}5 + 12 = 71{,}5 \]

Range dan IQR Data Kelompok

Range Data Kelompok

\[ \text{Range} = \text{tepi atas kelas terakhir} - \text{tepi bawah kelas pertama} \]

Contoh

Kelas pertama 0 sampai 19, kelas terakhir 80 sampai 99:

Range = 99,5 dikurangi (-0,5) = 100

IQR Data Kelompok

\[ \text{IQR} = Q_3 - Q_1 \]

Q1 = 34,5 dan Q3 = 71,5. IQR = 71,5 dikurangi 34,5 = 37

Range data kelompok (100) jauh lebih besar dari IQR (37). IQR lebih stabil untuk menggambarkan sebaran data yang sebenarnya.
